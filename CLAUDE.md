# skoor-web: the website skoor.it

The rules of the main repository (`Skoor-it/skoor-app`, CLAUDE.md) apply here too: plain words,
UK English, every text in English **and** Dutch, buttons never hidden (disabled, saying why), the
house colours, and the design board first: a page changes on its board (58–64) before it changes
here. See README.md for where everything is.

Checks before saying something works: `npm run build`, `npm test` (report the count), and
screenshots of the changed page on a phone (390 wide) and a computer (1440 wide), English and
Dutch. No model names anywhere in the repository.
